1. 기존 Supabase 이메일 로그인·회원가입·로그아웃 기능은 유지
2. 홈페이지에 DevFlow 로고, 검색창, 카테고리 메뉴, 로그인/회원가입 버튼 구현
3. 제목과 부제목이 있는 Hero 영역 구현
4. 카테고리별 게시글 필터링 기능 구현
5. 블로그 게시글 카드 목록 구현
6. 페이지네이션 구현
7. 최하단 Footer 구현
8. Supabase 클라이언트 SDK로 카테고리와 게시글 데이터 조회
9. RLS 정책, 테이블 생성, 관계 설정을 포함한 migration.sql 작성
10. 테스트용 seed.sql 작성
11. Supabase 마이그레이션은 직접 실행하지 말고 실행 명령어와 방법만 문서화
12. 기존 .env.local의 실제 키 값은 출력하거나 변경하지 않기
13. npm run build로 최종 검증
14. 오류가 발생하면 수정 후 다시 빌드
